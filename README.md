# One Glass OS

A modern, web-based operating system designed with a translucent frosted-glass theme. It provides a clean, distraction-free digital workspace equipped with productivity tools, customized applications, and desktop widgets directly inside your web browser.

---

## Built-In Applications

### 1. Glass Terminal (Advanced App)
A command-line terminal with a dual-tab interface in the title bar:
- **Terminal Tab**: Allows users to type and run interactive commands.
- **Commands Tab**: A built-in menu that displays all available system commands.
- **Available Commands**:
  - `help` - Lists all system commands.
  - `clear` - Clears the terminal screen.
  - `time` - Shows the current system time and date.
  - `open [app]` - Launches desktop applications.
  - `echo [text]` - Prints custom text to the screen.
  - `theme [dark/glass]` - Toggles a dark filter over the desktop.
  - `about` - Displays OS system details.

### 2. Glass Focus Suite
A productivity app designed to keep you focused on work or study:
- **Pomodoro Timer**: A 25-minute countdown timer with Start, Pause, and Reset controls.
- **Focus Goals**: A checklist to add daily tasks and cross them off when complete.
- **Widget Hub**: A central panel to toggle persistent desktop widgets on or off.

### 3. Weather Glass
A live weather forecast application:
- **Search Bar**: Look up weather details for any city around the world.
- **Metrics**: Displays local temperature, sky conditions, humidity levels, and wind speed.

### 4. System Settings
A system control window:
- **Master Volume**: Adjust system audio percentage.
- **Screen Dimmer**: Drag a slider to physically dim or brighten your desktop view.

### 5. Desktop Widgets & Dock
- **Frosted Flip Clock**: Displays a digital clock on your desktop.
- **Mini Calendar**: Displays today's day, date, and month.
- **Status Bar Dock**: A floating dock at the bottom of the screen for quick one-click app access.

---

## How to Use One Glass OS

1. **Enter the Desktop**: Click the "Launch" button or the "X" button on the Welcome screen.
2. **Open Applications**: Click any icon on the desktop or click any app slot on the bottom dock.
3. **Move Windows**: Click and drag the top title bar of any window or widget to move it around.
4. **Use Fullscreen**: Click the fullscreen symbol (⤢) in the top-right corner of a window.
5. **Explore the Terminal**: Open Glass Terminal, click the "Commands" tab to view available options, and switch back to "Terminal" to test commands.
